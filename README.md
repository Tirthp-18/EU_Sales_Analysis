# EU_Sales_Analysis


---

## 🚀 Project Overview
This project demonstrates an end-to-end data pipeline, starting from raw data generation using **Python** to advanced visual storytelling in **Tableau**. The dashboard provides a high-level executive summary of sales, profits, and customer metrics across various global regions.

## 🛠️ Tech Stack
*   **Data Generation/Wrangling**: Python (Pandas/NumPy) 
*   **Data Visualization**: Tableau
*   **Analysis Type**: Descriptive and Diagnostic Analytics

<br>

## 🔍 Key Insights from the Dashboard
As shown in **image_76e53d.png**, the analysis focuses on several critical business dimensions:

*   **Executive KPIs**: Real-time tracking of total Customers (9,934), unique Products (10,000), total Profit ($3.7M+), and total Sales ($25M+).
*   **Temporal Trends**: 
    *   **MoM Sales**: Tracking sales fluctuations from 2023 through 2026.
    *   **Ship Date Wise Profit**: Analyzing profitability trends based on logistics timelines.
*   **Geospatial Analysis**: A detailed map view covering European markets (France, Germany, Italy, etc.) to identify high-performing regions.
*   **Product Performance**: 
    *   **Sub-Category Analysis**: Identifying top revenue drivers like Machines, Chairs, and Accessories.
    *   **State-wise Breakdown**: Granular sales data across specific regions/states.
